# 按记 SnapLedger IPA 下载

[点击下载 SnapLedger.ipa](https://github.com/Sr-re/snapledger-downloads/raw/refs/heads/main/SnapLedger.ipa)

- 版本：0.1.0（Build 1），约 6 MB。
- 开发测试签名包，仅支持签名描述文件中已登记的设备。
- 主应用签名有效期：2026 年 10 月 19 日 19:04:59（北京时间）。到期后需重新签名。
- SHA-256：`8207c5c53a6631b1e5f716fdf02d3ab04965b6b49a84ce18330a1ec191840193`。

在 Mac 上打开 Apple Configurator，将 iPhone 通过 USB 连接并解锁、信任 Mac，然后选中设备，使用「添加 → App → 从我的 Mac 选择」添加下载的 IPA。开发者模式应保持开启，若系统要求信任开发者，请按系统提示操作。

公开下载不改变开发测试包的设备限制，未登记的设备需要重新签名后才能安装。
